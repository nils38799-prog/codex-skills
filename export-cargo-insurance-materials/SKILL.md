# 出口货运投保材料

按已有业务文件制作新一票投保材料。历史投保单是格式和填写范围的最高优先级参考。

## 模板选择

先查看目标票目录及相邻历史票，优先选择以下条件最接近的已完成投保单：

1. 相同货物品类。
2. 相同目的港或交货地。
3. 相同客户、贸易条款和运输方式。
4. 时间最近。

如果两个候选模板的填写范围或条款不同，先根据本票资料判断；差异会影响投保内容且无法可靠判断时，再向用户确认。

## 填写规则

- 只更新参考模板中原本已经填写、且本票资料能够确认的字段。
- 参考模板为空的字段必须继续留空，即使本票其他资料中能找到相应信息，也不得自行补填。
- 不新增备注、说明、来源、公式、工作表、行、列或附件类型。
- 不修改模板的文字标签、险别勾选、颜色、字体、边框、合并单元格、行列尺寸、分页、打印区域、页边距、工作表顺序及隐藏状态。
- 金额、件数、货物名称、港口、日期等均按模板现有表示方式填写，不自行改变大小写、日期格式、币种格式或精度。
- 保险金额按参考模板采用的投保比例计算；若模板比例、结汇发票金额或币种不明确，则先确认，不猜测。
- 投保金额以目标票“投保”或结汇用途的发票为准。报关发票与结汇发票金额不同时，不得混用。
- 船期等关键资料发生冲突时，指出来源和具体差异，请用户选择后再填写。
- 投保日期可按用户明确要求填写；没有要求时沿用该业务流程的既有惯例，不自行采用文件生成时间替代业务日期。

## 附件整理

参考同类历史票“投保”目录中的附件种类，只复制目标票已经存在的对应资料。保持 PDF 内容不变；仅在历史流程明确采用统一命名时才重命名副本。不得修改原始业务文件。

## 验证

完成后进行差异核验：

1. 确认只有计划更新的单元格值发生变化。
2. 将模板原为空的所有单元格与成品逐一比较，确认仍为空。
3. 确认工作表、样式、合并区域、打印设置以及其他工作簿结构没有变化。
4. 重新计算并检查公式错误；渲染投保单进行目视检查，确认没有截断、错位或格式变化。
5. 核对发票号、结汇发票金额、投保比例、保险金额、箱数、品名、起运港、目的港和已确认日期。
6. 保存到目标票的“投保”目录，并保留一份可供用户下载的输出文件。

交付时简要说明采用的模板、实际更新的字段、保险金额计算依据、已保留的空白字段及附件清单。不要声称填写了模板中实际保持为空的字段。
